# 盲文学习平台 · Braille Learning

> 轻量化、零依赖、即开即用的盲文学习平台 —— 汉字拼音盲文对照 · 语音朗读 · 交互刷题

## 一、项目简介

本项目面向视障人士及盲文学习者，提供一个纯前端、无需后端的盲文学习与练习工具。用户可通过**学习卡片**逐字认识盲文点阵，通过**实时转译**将汉字/拼音即时转换为盲文，通过**分类刷题**检验学习成果，并通过**生词本/错题本**进行针对性复习。

### 核心价值

- **社会价值**：助力信息无障碍，响应《"十四五"残疾人保障和发展规划》中"信息无障碍建设"要求
- **教育价值**：降低盲文学习门槛，提供随时随地可用的学习工具
- **技术价值**：纯前端零部署，手机浏览器打开即用，兼顾性能与可及性

## 三、技术栈

| 层面 | 技术 | 用途 |
|------|------|------|
| 结构 | HTML5 | 语义化标签，移动优先 |
| 样式 | CSS3 | CSS 变量主题系统、深色模式、响应式 |
| 逻辑 | 原生 JavaScript (ES5) | 零框架依赖，兼容性好 |
| 渲染 | Canvas 2D API | 高性能盲文点阵绘制，支持高 DPI |
| 语音 | Web Speech API | 中文语音朗读，含降级处理 |
| 存储 | localStorage | 个人学习数据本地持久化 |
| 盲文 | GB/T 15720 标准 | 中国盲文声母/韵母点位映射 |

### 为什么不用框架？

> 答辩术语：**"技术选型遵循最小依赖原则"**
>
> 本项目核心是数据映射与 Canvas 渲染，无复杂状态管理需求。使用原生 JS 可：
> 1. 减小体积（无框架运行时开销），首屏加载 < 50KB
> 2. 消除构建步骤，静态部署即可
> 3. 保证长期可维护性，不受框架版本迭代影响

### 模块化设计

> 答辩术语：**"IIFE 模块模式（Immediately Invoked Function Expression）"**
>
> 每个 JS 文件使用立即执行函数封装，形成独立作用域，仅通过返回值暴露公共接口。这是 ES6 模块（import/export）普及前的经典模块化方案，优点是：
> - 零构建、零打包，浏览器原生支持
> - 变量不污染全局，仅暴露必要接口
> - 依赖关系通过加载顺序显式表达

### 部署上线

#### 方式一：GitHub Pages（免费，推荐学生使用）

```bash

git add .
git commit -m "盲文学习平台"

git remote add origin https://github.com/你的用户名/braille-learning.git

```
然后在 GitHub 仓库 → Settings → Pages → Source 选 `main` 分支，几分钟后即可通过 `https://你的用户名.github.io/braille-learning/` 访问。

2. 登录 [vercel.com](https://vercel.com)，Import Project
3. Framework Preset 选 "Other"，直接 Deploy
4. 自动获得 `https://braille-learning.vercel.app` 地址

将 `index.html`、`css/`、`js/` 三个整体上传至服务器 Web 目录即可。

## 七、数据说明

### 为什么不用数据库？

> 答辩术语：**"数据分层存储策略"**
>
> 本项目将数据分为两类：
> - **静态数据**（字库、盲文规则）：打包进 JS，永不改变，无需数据库
> - **个人数据**（学习进度、生词本、答题记录）：用 localStorage 本地存储
>
> 只有当需要「账号系统 / 多端同步 / 排行榜」时才需引入后端。当前设计在保证功能完整的前提下，实现了**零运维成本**。

### localStorage 存储键

| 键名 | 内容 | 类型 |
|------|------|------|
| brl_learned | 已学字词列表 | string[] |
| brl_learnIndex | 学习当前位置 | number |
| brl_learnCat | 学习当前分类 | string |
| brl_starred | 生词本 | string[] |
| brl_quizScore | 刷题得分 | number |
| brl_quizTotal | 刷题总题数 | number |
| brl_quizCat | 刷题当前分类 | string |
| brl_wrongWords | 错题本 | string[] |
| brl_lastView | 上次访问页面 | string |
| brl_autoSpeak | 自动朗读开关 | boolean |

## 八、盲文标准说明

本项目采用 **中国盲文（GB/T 15720-1995《中国盲文》）** 标准：

- 盲文由 **6 个点位** 组成，排列为 2 列 × 3 行：
  ```
  1 4
  2 5
  3 6
  ```
- 每个汉字 → 拼音 → 声母点位 + 韵母点位
- 声母 21 个、韵母 35 个，均有对应点位编码
- 详见 `js/braille-data.js` 中的 `INITIALS` 和 `FINALS` 映射表

## 九、项目亮点（答辩重点）

1. **零依赖纯前端**：无框架、无构建、无后端，部署即用
2. **国标盲文引擎**：完整实现 GB/T 15720 声韵母点位映射
3. **高性能 Canvas 渲染**：自适应 DPI、主题色实时读取、尺寸动态计算
4. **分类学习体系**：9 大主题 204 字，支持分类学习与专项刷题
5. **完整学习闭环**：学习 → 转译 → 刷题 → 错题 → 复习
6. **无障碍设计**：深色模式、语音朗读、移动端适配、安全区适配
7. **健壮性**：localStorage 异常兜底、语音不支持降级、空数据友好提示
