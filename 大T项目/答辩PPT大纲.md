## 第 11 页 · 核心：盲文映射引擎（60 秒）

**标题**：国标盲文数据解析

**内容**：
- 遵循 **GB/T 15720-1995《中国盲文》** 国家标准
- 盲文 6 点位：`1 4 / 2 5 / 3 6`
- 映射链路：**汉字 → 拼音 → 声母点位 + 韵母点位**

**关键处理**：
- 声调归一化（ā→a, á→a, ǎ→a, à→a）
- y/w 开头音节归一化（yi→i, wu→u）
- j/q/x 后 u 自动转 ü
- 双盲符韵母拆分（如 iang → [2,4] + [1,3,4,6]）

**代码位置**：`js/braille-data.js`

> 🎤 口述："盲文引擎遵循国标 GB/T 15720，实现从汉字到盲文点位的完整映射。我们处理了声调归一化、y/w 音节转换等边界情况。"

## 第 12 页 · 核心：Canvas 渲染引擎（45 秒）

**标题**：高性能盲文点阵绘制

**内容**：
- Canvas 2D API 绘制，非 DOM 操作，性能更优
- **高 DPI 适配**：devicePixelRatio 倍率绘制，Retina 屏清晰
- **自适应尺寸**：根据容器宽度动态计算点直径
- **主题色实时读取**：getComputedStyle 读取 CSS 变量，深色模式无缝切换
- **圆角矩形兼容**：roundRect polyfill，兼容旧浏览器

**代码位置**：`js/braille-renderer.js`

> 🎤 口述："渲染引擎用 Canvas 绘制盲文点阵，支持高 DPI 屏幕自适应，并通过读取 CSS 变量实现深色模式无缝切换。"

## 第 13 页 · 数据存储方案（30 秒）

**标题**：localStorage 本地持久化

**内容**：
- **安全封装**：try-catch 兜底，隐私模式/存储满不崩溃
- **前缀隔离**：所有键以 `brl_` 前缀，避免与其他应用冲突
- **分级清除**：支持清全部 / 仅清错题本
- **显式重置**：清除后调用各模块 reset()，状态一致

> 🎤 口述："个人数据用 localStorage 存储，做了异常兜底和前缀隔离。清除数据时会显式重置所有模块状态，保证一致性。"

## 第 15 页 · 技术难点与解决（45 秒）

**标题**：踩过的坑

| 难点 | 解决方案 |
|------|----------|
| 盲文双盲符韵母拆分 | 按韵母类型查表拆分，如 iang 拆为两个盲符 |
| Canvas 隐藏时宽度为 0 | 视图切换后 requestAnimationFrame 重绘 |
| 高 DPI 屏模糊 | setTransform(dpr,...) 倍率绘制 |
| 深色模式色不同步 | getComputedStyle 实时读 CSS 变量 |
| 清除数据后状态不一致 | 各模块暴露 reset()，显式重置 |
| 语音列表异步加载 | onvoiceschanged 事件回调 |

> 🎤 口述："开发中我们遇到几个难点：盲文双盲符拆分、Canvas 隐藏时宽度为零、高 DPI 屏模糊等，都一一解决了。"
