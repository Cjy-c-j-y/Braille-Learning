# 项目逐模块解读（初学者版）

> 写给只略懂 Web 的你：用大白话把每个文件、每个标签、每个函数讲清楚。
> 读完这份，你就能在答辩时说出"这个模块是干什么的、用了什么技术"。

## 第 0 课：先搞懂三个基础概念

在看代码前，先用做菜来类比理解 Web 三件套：

| 技术 | 类比 | 一句话 |
|------|------|--------|
| **HTML** | 食材和盘子 | 决定页面"有什么"——标题、按钮、输入框 |
| **CSS** | 摆盘和装饰 | 决定页面"长什么样"——颜色、大小、位置 |
| **JavaScript (JS)** | 菜谱和动作 | 决定页面"会做什么"——点击后发生什么 |

> 举例：`<button>下一个</button>` 是 HTML（放一个按钮）；
> `button { background: blue; }` 是 CSS（按钮变蓝色）；
> `button.addEventListener('click', 下一题)` 是 JS（点击后执行下一题）。

## 第 1 课：HTML 标签速查（看 index.html 用）

`index.html` 是入口文件，里面全是"标签"。常见标签：

| 标签 | 作用 | 项目中的例子 |
|------|------|--------------|
| `<html>` | 整个网页的根 | 最外层 |
| `<head>` | 看不见的配置区 | 放标题、字符集、引入 CSS |
| `<body>` | 看得见的内容区 | 所有可见内容 |
| `<header>` | 顶部标题区 | "盲文学习平台"那行大字 |
| `<main>` | 主内容区 | 包住四个视图 |
| `<section>` | 一个区块 | 每个功能页（学习/转译/刷题/我的） |
| `<div>` | 通用盒子 | 到处都是，用来分组 |
| `<button>` | 按钮 | "下一个 →"、"🔊" |
| `<input>` | 输入框 | 转译页打字的地方 |
| `<canvas>` | 画布 | 画盲文点阵的地方（重点！） |
| `<nav>` | 导航区 | 底部四个 Tab |
| `<span>` | 小段文字 | 标签里的图标和文字 |

### 关键属性

- `class="learn-card"` → 给标签起类名，CSS 靠这个找它来美化
- `id="learnHanzi"` → 给标签起唯一身份证号，JS 靠这个找它来改内容
- `aria-label="朗读"` → 给屏幕阅读器读的无障碍标签（视障人士用）

### 项目里四个视图怎么切换的？

```html
<section class="view active" id="view-learn">  ← 有 active 就显示
<section class="view" id="view-translate">     ← 没有 active 就隐藏
```

CSS 里 `.view{display:none}` 默认隐藏，`.view.active{display:block}` 有 active 就显示。
JS 切换页面时就是给对应的 section 加上 `active` 类，其他的去掉。

## 第 2 课：CSS 速查（看 css/style.css 用）

### 选择器：怎么找到要美化的标签

```css
.learn-card { ... }        /* 类选择器：找 class="learn-card" 的 */
#learnHanzi { ... }        /* ID 选择器：找 id="learnHanzi" 的 */
button { ... }             /* 标签选择器：找所有 <button> */
```

### CSS 变量（项目大量使用）

```css
:root {
  --primary: #4f46e5;     /* 定义一个变量叫 --primary，值是紫色 */
}
.btn-main {
  background: var(--primary);  /* 用这个变量 */
}
```

**好处**：换主题色只改一处，全站跟着变。深色模式也是靠改这些变量实现的。

### 媒体查询：自动适配深色模式

```css
@media (prefers-color-scheme: dark) {
  :root { --bg: #0e1016; ... }   /* 系统切深色时，变量自动变 */
}
```

### 响应式：适配小屏

```css
@media (max-width: 400px) {
  .learn-hanzi { font-size: 52px; }  /* 屏幕小于 400px 时字变小 */
}
```

## 第 3 课：JS 基础速查（看 js/ 用）

### 变量：装数据的盒子

```javascript
var index = 0;           // 数字
var words = BrailleData.DICT;  // 数组（一排数据）
var learnedSet = {};     // 对象（键值对）
```

### 函数：一段可重复执行的动作

```javascript
function render() {        // 定义函数叫 render
  // ...要做的事
}
function init() {          // init = 初始化
  bind();                  // 调用另一个函数
  render();
}
```

### 模块（IIFE 模式）：项目核心写法

```javascript
var LearnModule = (function () {
  // 私有变量（外面看不到）
  var index = 0;

  // 私有函数
  function render() { ... }

  // 暴露给外面的接口
  return { init: init, refresh: refresh, reset: reset };
})();
```

**类比**：模块像一个"黑盒子工厂"，外面只能通过它暴露的接口（init/refresh/reset）来操作，内部细节看不到。这样变量不会互相干扰。

### 事件监听：用户点击后发生什么

```javascript
btnNext.addEventListener('click', function () {
  index = (index + 1) % words.length;  // 点一次，index 加 1
  render();                             // 重新渲染
});
```

## 第 4 课：逐个 JS 文件解读

### 📦 js/braille-data.js — 盲文数据引擎（最核心）

**干什么**：把汉字变成盲文点位。比如"你" → nǐ → [1,3,4,5]（点位编号）。

**关键内容**：
- `INITIALS`：声母表，记录 b/p/m/f... 对应哪些点位
- `FINALS`：韵母表，记录 a/o/e/i... 对应哪些点位
- `DICT`：字库，204 个字，每个有 `c`(汉字) `p`(拼音) `s`(例句) `cat`(分类)
- `CATEGORIES`：9 个分类的元数据（名字、图标）
- `pinyinToCells(py)`：核心函数，拼音 → 盲文点位数组

**答辩怎么说**：
> "这是盲文引擎，遵循国标 GB/T 15720。汉字先转拼音，再查声母表和韵母表，拼出盲文点位。"

---

### 💾 js/store.js — 本地存储模块

**干什么**：把学习进度、生词本等数据存到浏览器里，关掉再打开还在。

**关键函数**：
- `Store.get(key, 默认值)`：读取数据
- `Store.set(key, val)`：保存数据
- `Store.remove(key)`：删除某条
- `Store.clearAll()`：清空所有（带 `brl_` 前缀的）

**技术点**：用 `localStorage`，所有操作包了 try-catch，隐私模式也不会崩。

**答辩怎么说**：
> "用 localStorage 做本地持久化，try-catch 兜底保证健壮性。"

---

### 🎨 js/braille-renderer.js — Canvas 渲染模块

**干什么**：在画布上画出盲文的 6 个点（实心或空心）。

**关键函数**：
- `draw(canvas, cells, opt)`：在指定 canvas 上画盲文
  - `canvas`：哪个画布
  - `cells`：点位数组，如 `[[1,3,4,5]]`
  - `opt`：配置（最大宽度、点的大小等）

**技术点**：
- 用 `devicePixelRatio` 适配高清屏（Retina 不模糊）
- 用 `getComputedStyle` 读 CSS 变量，深色模式自动跟着变

**答辩怎么说**：
> "用 Canvas 2D API 绘制盲文点阵，做了高 DPI 适配和主题色实时同步。"

---

### 🔊 js/speech.js — 语音朗读模块

**干什么**：点 🔊 按钮时，用浏览器自带功能读出汉字。

**关键函数**：
- `Speech.speak(text)`：朗读文字
- `Speech.stop()`：停止朗读
- `Speech.supported`：当前浏览器是否支持

**技术点**：用 Web Speech API，浏览器原生功能，不用装任何东西。

**答辩怎么说**：
> "用 Web Speech API 做中文语音朗读，不支持时降级提示，不影响其他功能。"

---

### 🔧 js/utils.js — 工具函数

**干什么**：放三个到处都要用的小工具。

- `$(id)`：`document.getElementById` 的简写，靠 id 找元素
- `shuffle(arr)`：随机打乱数组顺序（刷题打乱选项用）
- `debounce(fn, wait)`：防抖，连续操作只执行最后一次（转译输入用）

---

### 📖 js/learn.js — 学习模块

**干什么**：学习页那一整套——展示卡片、切分类、收藏、下一个。

**关键变量**：
- `allWords`：全部 204 字
- `category`：当前选的分类（如 'person'）
- `words`：当前分类下的字
- `index`：看到第几个了
- `learnedSet`：已经学过哪些字

**关键函数**：
- `getWords()`：按分类筛出字
- `buildCatBar()`：渲染顶部分类切换栏
- `render()`：渲染当前卡片（汉字、拼音、盲文、例句、进度）
- `bind()`：绑定按钮事件（朗读、收藏、下一个）
- `init()`：初始化（恢复上次位置、绑定事件、渲染）
- `refresh()`：刷新（切回页面时重绘画布）
- `reset()`：重置（清空数据时调用）

**答辩怎么说**：
> "学习模块支持 9 大分类，卡片式展示汉字、拼音、盲文点阵和例句，进度本地持久化。"

---

### ⌨️ js/translate.js — 转译模块

**干什么**：转译页——输入汉字或拼音，实时显示盲文。

**关键函数**：
- `tokenize(str)`：分词（汉字逐字拆、拼音按空格拆）
- `render()`：渲染转译结果（每个字一个小卡片，带盲文）
- `lazyRender`：防抖版的 render（输入停 120ms 才触发）

**流程**：用户输入 → tokenize 分词 → 每个词查盲文 → Canvas 画出来

**答辩怎么说**：
> "转译模块支持汉字和拼音输入，用防抖优化性能，实时显示盲文点阵。"

---

### 🎯 js/quiz.js — 刷题模块

**干什么**：刷题页——出题、选项、判分、记录错题。

**关键变量**：
- `category`：当前刷的分类
- `current`：当前这道题
- `round`：第几题了
- `locked`：答过了就锁住，不能再点

**关键函数**：
- `getPool()`：按分类筛题库
- `buildCatBar()`：渲染分类栏
- `newQuestion()`：生成新题（随机选正确答案 + 3 个干扰项 + 打乱）
- `renderQuestion()`：渲染题干和选项（两种题型：看盲文选字 / 看字选盲文）
- `answer(chosenChar, btnEl)`：判分（对/错、记分、记错题、高亮正确答案）
- `reset()`：重置（清空数据时调用）

**两种题型**：
- `b2c`（盲文辨汉字）：题面是盲文，选项是汉字
- `c2b`（汉字辨盲文）：题面是汉字，选项是盲文

**答辩怎么说**：
> "刷题模块支持双向出题和分类筛选，答错自动归档到错题本，形成学习闭环。"

---

### 👤 js/me.js — 我的模块

**干什么**："我的"页——统计数字、生词本、错题本、清空按钮。

**关键函数**：
- `renderWordItem(ch, listEl, onRemove)`：渲染一个字词条目（生词本和错题本共用）
- `render()`：渲染统计 + 生词本列表 + 错题本列表
- `init()`：绑定两个清空按钮（清错题本 / 清全部）

**两个清空按钮的区别**：
- `btnClearWrong`：只清错题本（`Store.remove('wrongWords')`）
- `btnClear`：清全部（`Store.clearAll()` + 调用各模块 `reset()`）

**答辩怎么说**：
> "我的模块汇总学习数据，提供生词本和错题本两个复习工具，支持分级清除。"

---

### 🎮 js/app.js — 主控模块

**干什么**：统筹全局——切换页面、响应窗口变化、深色模式切换、启动所有模块。

**关键逻辑**：
- `switchView(name)`：切换页面（改 active 类、重绘画布、记忆上次页面）
- 监听 `resize`/`orientationchange`：窗口变了重绘画布
- 监听 `prefers-color-scheme` 变化：系统切深色模式时重绘
- 监听 `visibilitychange`：页面切到后台时停止朗读
- 启动顺序：`LearnModule.init()` → `TranslateModule.init()` → `QuizModule.init()` → `MeModule.init()`

**答辩怎么说**：
> "主控模块负责视图切换、全局响应和模块启动，保证各模块协同工作。"

## 第 5 课：数据流——一次完整的学习过程

以"用户在学习页点下一个"为例，看数据怎么流动：

```
1. 用户点击 "下一个 →" 按钮
        ↓
2. btnNext 的 click 事件触发
        ↓
3. JS 执行: index = (index + 1) % words.length
   （index 加 1，超过总数就回到 0）
        ↓
4. 调用 render()
        ↓
5. render() 做了这些事:
   a. 取出 words[index] 这个字
   b. 把汉字塞进 elHanzi（DOM 更新）
   c. 把拼音塞进 elPinyin
   d. 调用 BrailleData.pinyinToCells(拼音) 算出盲文点位
   e. 调用 BrailleRenderer.draw(canvas, 点位) 画出来
   f. 把这个字记进 learnedSet
   g. Store.set('learned', ...) 存到本地
   h. 更新进度条宽度
        ↓
6. 页面显示新的字
```

## 第 6 课：数据流——一次刷题过程

```
1. 进入刷题页 → QuizModule.init() → newQuestion()
        ↓
2. newQuestion() 生成题:
   a. 随机选题型 (b2c 或 c2b)
   b. 从题库随机选 1 个正确答案
   c. 随机选 3 个不重复干扰项
   d. shuffle 打乱 4 个选项
   e. 调用 renderQuestion() 画出来
        ↓
3. 用户点一个选项 → answer() 触发
        ↓
4. answer() 做了这些事:
   a. 判断对错
   b. Store.set('quizScore'/'quizTotal') 更新分数
   c. 如果错: Store.set('wrongWords') 记进错题本
   d. 高亮正确/错误选项
   e. 显示反馈文字
   f. MeModule.render() 刷新"我的"页统计
        ↓
5. 用户点 "下一题 →" → 又回到第 2 步
```

## 第 7 课：清空数据按钮的修复（你提的问题）

**原来的问题**：
```javascript
Store.clearAll();          // 清了 localStorage
render();                  // 刷新了"我的"页
LearnModule.refresh();     // 刷新了学习页
location.reload();         // 重新加载整个页面（依赖这个来重置刷题页）
```

问题：如果 reload 没执行成功，刷题页的得分和题号还是旧的。

**修复后**：
```javascript
Store.clearAll();          // 清 localStorage
LearnModule.reset();       // 显式重置学习模块（index 归零、分类归全部）
QuizModule.reset();        // 显式重置刷题模块（题号归零、分数清零、出新题）
render();                  // 刷新"我的"页
```

每个模块都暴露了 `reset()` 方法，清空时挨个调用，不依赖 reload。
